# Real Madrid Club Management System

## Description
This is a console Java application for managing a football club.

The program allows:
- adding players
- removing players
- viewing club players
- managing club budget

## Technologies
- Java
- OOP
- Git
- GitHub

## OOP Principles Used
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction
- Exception Handling

## How to Run
1. Open project in IntelliJ IDEA
2. Run Main.java

## Features
- Add player
- Remove player
- Show players
- Show budget
- Exception handling
